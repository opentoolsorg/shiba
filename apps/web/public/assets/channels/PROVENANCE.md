# Brand Assets Provenance

This directory contains brand marks used strictly for nominative identification of supported integration surfaces and external tools.

## Upstream Sources (Simple Icons v16.24.1)

The following SVG assets were sourced from [Simple Icons](https://simpleicons.org/) at pinned release `v16.24.1`:

- **GitHub** (`github.svg`)
  - Upstream URL: `https://raw.githubusercontent.com/simple-icons/simple-icons/16.24.1/icons/github.svg`
  - Upstream License: [CC0 1.0 Universal (CC0-1.0)](https://creativecommons.org/publicdomain/zero/1.0/) Public Domain Dedication
  - Adaptations: Fixed dark `#24292f` fill glyph on a fixed white background chip container (`bg-white` / `#ffffff`). Removed `@media (prefers-color-scheme: dark)` to ensure legibility across mixed application and operating system color themes.
  - Verification: Path `d` attribute matches upstream byte sequence.

- **Linear** (`linear.svg`)
  - Upstream URL: `https://raw.githubusercontent.com/simple-icons/simple-icons/16.24.1/icons/linear.svg`
  - Upstream License: [CC0 1.0 Universal (CC0-1.0)](https://creativecommons.org/publicdomain/zero/1.0/) Public Domain Dedication
  - Adaptations: Added official brand fill `#5E6AD2`.
  - Verification: Path `d` attribute matches upstream byte sequence.

- **Gmail** (`gmail.svg`)
  - Upstream URL: `https://raw.githubusercontent.com/simple-icons/simple-icons/16.24.1/icons/gmail.svg`
  - Upstream License: [CC0 1.0 Universal (CC0-1.0)](https://creativecommons.org/publicdomain/zero/1.0/) Public Domain Dedication
