---
title: Discord
description: Queue a Shiba task from Discord and review it before work starts.
---

Use the `/shiba` command in a connected Discord channel or direct message. Shiba replies with a request you can review before allowing the work to start.

## Before you start

Your administrator must connect the Shiba app, register its command, and choose who can approve work. If `/shiba` is missing, ask them to check the installation.

## Send a task

Choose `/shiba`, then enter a clear task and the GitHub repository URL:

```text
/shiba task: fix the broken README link repo: https://github.com/owner/repo
```

You can omit `repo` when the channel has a default repository. Keep the request small enough that you can review its result.

## Review the approval

Read the proposed task and repository, including any continuation messages for a long request. Choose **Approve** to allow it or **Reject** to stop it.

Only configured approvers can decide. Discord approvals are handled in the channel, not on the dashboard. If a button refuses your decision, ask your administrator to check your access.

## Read the outcome

Shiba posts progress and the result to the channel. Open any pull request link and check the changes and reported tests. Wait for the result and reported checks before adopting changes.

## Setup

For app installation, permissions, and command registration, see [Discord setup](/docs/discord-setup/).
