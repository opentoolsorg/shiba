Shiba is a workspace for AI employees. Give each employee a role, instructions, and the tools it needs to help with the work behind your company.

Start with a marketing brief, a research report, an operating checklist, or a code change. Explain the outcome, provide context, and review the result before using it.

## A role for the work you do

- **Marketing and sales:** campaign drafts, launch plans, account briefs, and outreach copy for review.
- **Research and operations:** evidence-based summaries, runbooks, handoffs, and checklists.
- **Product and design:** specifications, user flows, interface copy, and prototype plans.
- **Engineering and QA:** focused code changes, tests, and review findings.
- **Finance:** draft budgets and analysis from figures you supply.

Roles are reusable instructions, not a promise of expertise or access. Start from a [template](/docs/templates/) or write your own brief. The employee can use only the connections and permissions available to it.

## From a brief to a result

1. **Choose an employee.** Set its job, working style, and expected output.
2. **Give it context.** Share the facts, files, and limits that matter to the task.
3. **Approve the work.** Check the proposed request before a workspace task runs. Connected app actions follow their own permissions and approval rules.
4. **Review the result.** Read the draft, inspect the changes, and check the evidence. Ask for another pass in the same thread.

A draft stays a draft until you decide what to do with it. Publishing a pull request requires a separate approval of the completed changes.

## Choose where work happens

You do not need GitHub for every task. An **artifact workspace** is a place to create reviewable files without a repository. Use a **repository task** when working on an existing codebase, or **employee tools and supplied context** for a task using permitted app resources.

Learn more about [threads and results](/docs/dashboard/), [connections](/docs/connections/), and [approvals](/docs/approval-gates/).

## Make the next task easier

Keep related work in a thread and [share team context deliberately](/docs/team-workspaces/). Save repeatable instructions as [skills](/docs/skills/), and use [automations](/docs/automations/) for supported recurring requests. Creating a skill or schedule does not grant new app access or approve future work.

Shiba is open-source and self-hosted. Your installation needs a working model connection and the runtime for the tasks you choose. Hosting and model usage may cost money; see [costs](/docs/costs/).
