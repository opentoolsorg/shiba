## Do I need GitHub?

Only for a repository task. Choose **Artifact workspace** to create files without a repository, or **Employee tools and supplied context** for work using a linked brief or granted app resources. See [Your first task](/docs/getting-started/).

## Where are my AI employees?

Open **Agents**. Some controls still say **Create bot**, **Edit bot**, or **Launch bot**; these manage your employee profiles. Check that you are in the right personal or team workspace.

## I can't sign in

Check that you are using the right Shiba address and an account allowed into that workspace. If you still cannot get in, ask the person who manages the installation.

## My task is waiting

Look in **Approvals** for a pending decision. Read the request before approving it. If it is not yours to approve, ask an authorized workspace member.

For local work, also check that the selected computer is connected and available. Do not start another copy of the task until you understand the current status.

## My task failed

Read the error in the thread. It may need a working model connection, an available runtime, repository access, or a smaller brief. Keep the error message when asking your workspace operator for help.

A failed task has not produced a verified result. Review any partial files and reported checks before using them.

## I don't see a pull request or file

A task can return changes without publishing. If publication was requested, check for the separate approval after the work finishes, then check any publishing error.

For artifact work, look for **Deliverables** or **Download artifacts ZIP**. Read missing-file and size-limit notices; ZIP links expire after seven days. See [Threads and results](/docs/dashboard/).

## An app is listed but my employee cannot use it

Check the provider setup, signed-in account, and employee **Tool policy**. A catalog entry, logo, or template does not grant access. See [Connections and tools](/docs/connections/).

## My skills are missing

Check the signed-in account, selected workspace, skill type, and disabled or archived views. Current skills are stored with the account or workspace. Older browser-local notes may need **Import legacy skills as drafts** from **Run-attached skills** in the browser where they were saved. See [Skills](/docs/skills/).

## I need help with an installation

Use [Self-hosting](/docs/self-hosting/) and the [readiness checklist](/docs/readiness/). Developers can use [Local development](/docs/local-development/).

When reporting a problem, include what you tried, what you expected, and the error you saw. Remove passwords, tokens, and private conversation details before sharing.
