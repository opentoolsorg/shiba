title: Common questions
description: Find the next step when you're stuck with a task or your workspace.
---

## I can't sign in

Check that you're using the right Shiba address and an account allowed into that workspace. If you still can't get in, ask the person who manages the installation.

## My task is waiting

Look in **Approvals** for a request waiting on a decision. Read it before approving. If it isn't yours to approve, ask your workspace owner to review it.

## My task failed

Read the error in the thread. It may need a different repository, a working model connection, or a smaller brief. Keep the error message when asking your workspace owner for help.

A failed task hasn't produced a verified result. Check the files and reported tests before using any partial work.

## I don't see a pull request

A task can return changes without opening a pull request. Check whether publication was requested and whether the thread reports a publishing error. See [reviewing changes](/docs/review/).

## My saved skills are missing

Skills are saved in the browser where you created them. Try that browser and profile. Clearing site data removes them; see [Skills](/docs/skills/) for storage details.

## I need help with an installation

Use the [self-hosting guide](/docs/self-hosting/) and [readiness checklist](/docs/readiness/). Developers working locally can use [local development](/docs/local-development/).

When reporting a problem, include what you tried, what you expected, and the error you saw. Remove passwords, tokens, and private conversation details before sharing.
