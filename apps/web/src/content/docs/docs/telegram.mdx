title: Telegram

Use Shiba from a Telegram direct message or group chat. A task stays pending until someone allowed to approve it chooses **Approve**.

## Before you start

Ask your administrator for the connected Shiba bot and confirm that your Telegram account can approve work. The administrator must set up the bot before commands will work.

## Send a task

Send the bot a repository URL and a clear request:

```text
/shiba https://github.com/owner/repo fix the broken README link
```

In a group, you can address the bot as `/shiba@YourBot`. If the chat has a default repository, you can omit the URL. Use `/help` to see the command format.

## Review the approval

Check the full task and repository in the reply. Choose **Approve** to allow that request or **Reject** to stop it. A changed request needs a new review.

Only configured approvers can decide. Telegram approvals are handled in that chat; do not look for the same card in the dashboard.

## Read the outcome

Shiba posts progress and the result back to the chat. Follow any pull request link and inspect the actual changes and checks. If a run fails, read its error before starting another.

## Setup

If the bot does not reply or refuses your approval, ask your administrator to check [Telegram setup](/docs/telegram-setup/).
