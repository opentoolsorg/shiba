# Shiba brand mark

One geometric Shiba-dog drawing, generated rasters. Sources:

- `shiba-mark.svg` — the bare dog mark in a 64×64 box. This is the geometry
  used by `apps/frontend/src/components/ShibaMark.tsx` and the public marketing
  robot mark. Use it for inline UI marks, favicons and OG images.
- `shiba-mark-tile.svg` — the app-icon plate: white paper, a neutral hairline,
  the dog mark at 70% of the plate height. Use it for PWA, Apple touch, Electron
  and tray sources.

Palette: outer fur `#e07a5f`, ear shadow `#c96f4a`, inner ear `#f2b29b`,
muzzle `#fff3e8`, features `#171717`, plate `#ffffff`, hairline `#171717` at 12%.

Rasters in `apps/frontend/public/app/`: `icon-192.png`, `icon-512.png`,
`icon-maskable-512.png`, `apple-touch-icon.png`, `favicon-32x32.png`,
`favicon.ico`, and `favicon.svg`.
