This directory is a build-only cache of exact public Debian packages. Binary files
are generated by `node --use-env-proxy apps/backend/computer/precache-debs.mjs`
with Node 24 and must not be committed. The helper reads only the adjacent reviewed
manifest and accepts no command arguments. Existing proxy and TLS trust remain in
effect; no credentials are required or copied into the image.

The manifest records came from the signature-verified Bookworm package index at
`20261105T000000Z`. Official content-addressed Snapshot URLs avoid failing timestamp
redirect lookups. Every complete response must match the index's exact byte count
and SHA-256 before an atomic cache publication. The helper refuses redirects,
foreign hosts, oversized bodies, changed cached files and symlink destinations.

APT must still verify the unchanged signed snapshot metadata and select these same
versions. This cache does not permit an unsigned package, a mutable repository
fallback or a different dependency version. Missing or invalid data stops the
prefetch and must stop the build. A successful prefetch does not prove the image
build, offline desktop acceptance or deployed Cloudflare runtime works.

Primary API reference: <https://salsa.debian.org/snapshot-team/snapshot/raw/master/API>.
Snapshot usage: <https://snapshot.debian.org/>.
