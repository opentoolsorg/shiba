# Worker secrets reference

Generated by `node scripts/secrets-doc.mjs` from `apps/backend/worker-secrets.json`.
Lists binding **names** only; never store values in git.

| Name | Required | Purpose | Feature affected if unset |
| --- | --- | --- | --- |
| `AI_GATEWAY_TOKEN` | optional | AI Gateway uses the AI binding and GATEWAY_ID, not a container provider key. Optional: sent as cf-aig-authorization on gateway requests (src/egress.ts). Required when the gateway is auth-gated or has no BYOK key stored. | AI Gateway authorization on egress |
| `ARTIFACT_SIGNING_KEY` | optional | undocumented | Signed intake headers and artifact downloads |
| `BETTER_AUTH_BOOTSTRAP_TOKEN` | optional | First dashboard account on a public host. Set one of these before sign-up. The sign-up form sends the token as x-shiba-bootstrap-token. Loopback dev can create the first account without either. | Built-in dashboard email/social sign-in |
| `BETTER_AUTH_GOOGLE_CLIENT_ID` | optional | Optional social sign-in for existing, locally verified dashboard accounts. Both credentials are required. Callback: /api/auth/callback/google. | Built-in dashboard email/social sign-in |
| `BETTER_AUTH_GOOGLE_CLIENT_SECRET` | optional | Optional social-login OAuth client secrets; configure matching client IDs separately. | Built-in dashboard email/social sign-in |
| `BETTER_AUTH_OWNER_EMAIL` | optional | Allowlisted email for that first account. Compared case-insensitively. | Built-in dashboard email/social sign-in |
| `BETTER_AUTH_SECRET` | optional | Built-in dashboard auth lane (better-auth.ts): email+password accounts and signed-cookie sessions at /api/auth/*, backed by the AGENT_AUDIT D1 database. The library requires >=32 chars; unset/shorter = lane dark and the gate falls back to Access / fail-closed. `pnpm run bootstrap` asks and generates one when accepted. | Built-in dashboard email/social sign-in |
| `BETTER_AUTH_SLACK_CLIENT_ID` | optional | Slack OpenID sign-in, separate from Slack app installation credentials/scopes. Both credentials are required. Callback: /api/auth/callback/slack. | Built-in dashboard email/social sign-in |
| `BETTER_AUTH_SLACK_CLIENT_SECRET` | optional | undocumented | Built-in dashboard email/social sign-in |
| `CLAUDE_SUBSCRIPTION_TOKEN` | optional | Optional deployment-wide operator lanes (not the Dashboard Providers OAuth path). Per-user sign-in on /app Providers uses MODEL_CREDENTIAL_KEY + UserProviderOAuth instead of these secrets for Codex, Claude, Cursor, Grok, and Antigravity. T48: `claude setup-token` when SHIBA_CLAUDE_SUBSCRIPTION=1 and no per-user token. | Deployment-wide subscription harness lane |
| `CODEX_SUBSCRIPTION_AUTH_JSON` | optional | T49: `codex login` auth.json when SHIBA_CODEX_SUBSCRIPTION=1 and no per-user SIWC. | Deployment-wide subscription harness lane |

| `DISCORD_PUBLIC_KEY` | optional | Discord interactions lane (POST /api/discord/interactions) — the app's Ed25519 public key, used to verify request signatures. | Discord interactions lane |
| `FOUNDER_HUBSPOT_CREDENTIAL_KEY` | optional | Worker-only HubSpot capture encryption key (64 hex); supplied token is separate. | Native founder reads (Stripe, Meta, HubSpot) |
| `FOUNDER_META_CREDENTIAL_KEY` | optional | Worker-only Meta encryption key (64 hex), separate from account credentials. | Native founder reads (Stripe, Meta, HubSpot) |
| `FOUNDER_STRIPE_CREDENTIAL_KEY` | optional | Worker-only encryption key (64 hex); separate from account credentials. | Native founder reads (Stripe, Meta, HubSpot) |
| `GITHUB_APP_ID` | optional | Optional GitHub App (multi-repo). Worker mints installation tokens; never sent to containers. | GitHub clone, PR publish, App installs, or webhooks |
