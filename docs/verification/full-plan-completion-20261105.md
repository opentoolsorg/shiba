A source or fixture test is not a deployed service pass. Historical browser reports keep their original revisions and fixture limitations. Their test totals are not totals for this baseline.

## Continuation verification after the baseline

The artifact owner implemented incremental ZIP output with the existing STORE method, published in checkpoint `419c440`. Frozen decoded capture bytes are checked before the first await. A deterministic first pass computes length and SHA-256 without a complete ZIP buffer. A second pass writes bounded chunks through native `FixedLengthStream`, supplying the checksum to R2. Both the producer and private upload acknowledgment finish before the bundle is returned. This closes the literal output streaming gap in that checkpoint, while retaining the bounded source snapshot and buffered adapter for callers explicitly requesting bytes.

The independent reviewer read `workspace-archive.ts`, `run-deliverables.ts`, the `OpenCodeAgent` signal call site, `vitest-setup.ts`, `workspace-artifacts.test.ts` and `workspace-archive-worker.test.ts`.
