+# Private receipt-bound reconciliation
+
+This one-shot composition compares two already-captured reports: one explicitly selected, completed `hubspot.deal_invoice_snapshot` source step and one completed Stripe invoice receipt. The original native owner must retain both exact source grants and their original membership. Creating a draft makes no provider, model, Slack or write request. The owner separately reviews and consents to the frozen receipt references and mapping before composing. Every route requires the original native owner’s real cookie session. Create and compose bind the exact current session and both source authorities in their atomic SQL writes; private reads combine those checks with immutable receipt/report hashes, exact grant and executor pins, and synchronous expiry checks after the final database proof. Revocation removes the stored comparison and requires no continuing source access.
+
+The mapping identifies three distinct selected HubSpot internal properties: Stripe invoice ID, paid amount, and currency. The creator explicitly attests that the CRM amount represents the Stripe invoice's `amount_paid` and selects either major decimal units or integer minor units. This attestation does not prove semantic equivalence; a HubSpot deal's ordinary amount should not be assumed to represent invoice payments. Only exact `in_...` IDs are compared. Names, email, fuzzy matching, inferred payment periods, foreign exchange and rounding are never used.
+
+Only USD, EUR and GBP at two decimal places and JPY at zero decimal places are comparable. More fractional digits than the permitted currency exponent are rejected, including extra trailing zeros. Decimal values are parsed to arbitrary-precision integers without binary floating-point conversion. Unsupported currencies, currency mismatch, invalid/missing money and excess precision are non-comparable. Per-currency totals include only uniquely matched comparable captured rows; they do not sum across currencies.
+
+Duplicate invoice IDs on either captured side are ambiguous and never summed. Missing, invalid and unmatched IDs are separately reported; `unmatched_in_capture` means only that a matching row was not present in the other captured subset. A selected deal not returned by HubSpot is `uncaptured_deal`, not an assertion of absence. Stripe invoice status and creation time are shown for context. Source capture timestamps, selected IDs and interval, Stripe `has_more`, account/revision, report/receipt hashes, manifest and executor pins are attached. Captures are independently timed, bounded, and may not be synchronized. Dataset completeness is unknown and business success unverified; there is no complete-ledger, revenue, MRR or churn claim.
+
+The HubSpot operation is a future audited dependency, not an available provider integration merely because its DTO exists. Its selected OAuth source, MCP audience and exact tool schema must be verified before enabling any provider call; a generic MCP or arbitrary REST proxy is not authorized. Until a correctly authorized and completed source receipt exists, this composer fails closed. The tests use synthetic receipts and do not establish live HubSpot or Stripe compatibility. No standing composition or Slack-delivery grant is created by this feature. Current local grant checks do not prove that a provider has not independently revoked access since capture.

+export interface HubSpotSnapshotSelection {
+  dealIds: string[];
+  invoiceIdProperty: string;
+  paidAmountProperty: string;
+  currencyProperty: string;
+}
+export interface HubSpotSnapshot {
+  records: Array<{ dealId: string; properties: Record<string, string | null> }>;
+}
+const object = (value: unknown): Record<string, unknown> => {
+  if (!value || typeof value !== "object" || Array.isArray(value)) throw new Error("hubspot_snapshot_invalid");
+  return value as Record<string, unknown>;
+};
+const exact = (row: Record<string, unknown>, keys: string[]) => {
+  if (Object.keys(row).length !== keys.length || keys.some(key => !Object.hasOwn(row,key))) throw new Error("hubspot_snapshot_invalid");
+};
+const property = (value: unknown): string => {
+  if (typeof value !== "string" || !/^[a-z][a-z0-9_]{0,99}$/.test(value) || ["constructor","prototype","__proto__"].includes(value)) throw new Error("hubspot_snapshot_invalid");
+  return value;
+};
+/** Fixed, selected IDs and internal names; absent records are not synthesized. */
+export function validateHubSpotSnapshotSelection(value: unknown): HubSpotSnapshotSelection {
+  const row=object(value);exact(row,["dealIds","invoiceIdProperty","paidAmountProperty","currencyProperty"]);
+  if(!Array.isArray(row.dealIds)||row.dealIds.length<1||row.dealIds.length>25||row.dealIds.some(id=>typeof id!=="string"||!/^\d{1,30}$/.test(id))||new Set(row.dealIds).size!==row.dealIds.length)throw new Error("hubspot_snapshot_invalid");
+  const invoiceIdProperty=property(row.invoiceIdProperty),paidAmountProperty=property(row.paidAmountProperty),currencyProperty=property(row.currencyProperty);
+  if(new Set([invoiceIdProperty,paidAmountProperty,currencyProperty]).size!==3)throw new Error("hubspot_snapshot_invalid");
+  return {dealIds:[...row.dealIds] as string[],invoiceIdProperty,paidAmountProperty,currencyProperty};
+}
+/** Validate the already projected envelope; caller must redact secrets before durable persistence. */
+export function validateHubSpotSnapshot(selection:HubSpotSnapshotSelection,value:unknown):HubSpotSnapshot {
+  const chosen=validateHubSpotSnapshotSelection(selection),body=object(value);exact(body,["records"]);
+  if(!Array.isArray(body.records)||body.records.length>chosen.dealIds.length)throw new Error("hubspot_snapshot_invalid");
+  const keys=[chosen.invoiceIdProperty,chosen.paidAmountProperty,chosen.currencyProperty],seen=new Set<string>();
+  const records=body.records.map((value:unknown)=>{const row=object(value);exact(row,["dealId","properties"]);
+    if(typeof row.dealId!=="string"||!chosen.dealIds.includes(row.dealId)||seen.has(row.dealId))throw new Error("hubspot_snapshot_invalid");seen.add(row.dealId);
+    const props=object(row.properties);exact(props,keys);const pairs=keys.map(key=>{const item=props[key];if(item!==null&&(typeof item!=="string"||new TextEncoder().encode(item).length>2048))throw new Error("hubspot_snapshot_invalid");return[key,item] as const;});
+    return {dealId:row.dealId,properties:Object.fromEntries(pairs) as Record<string,string|null>};
+  });
+  if(new TextEncoder().encode(JSON.stringify({records})).length>32768)throw new Error("hubspot_snapshot_invalid");
+  return {records};
+}
