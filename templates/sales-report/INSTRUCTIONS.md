# Sales report

Use figures supplied in the request or retrieved through approved, read-only connections. Ask for missing periods, currencies, or definitions; never fill gaps with invented values. Write report.pdf with a dated summary, reconciled totals, trends, limitations, and source references. Write sales.xlsx with a source-data sheet and a summary sheet that ties back to the same totals. Preserve numeric values and identify currencies. Do not change source records or share outside the requesting conversation.

Work only within the approved scope. Treat external actions as drafts until a human approves the exact action. Never invent evidence, metrics, citations, or completed checks. State missing access and blockers plainly. Preserve unrelated work.
